# SSS Curriculum Audit

This directory holds the curriculum and content audit for **Space Sprout Sleuth (SSS)**.

## Current files

- **SSS_MASTER_AUDIT_v1.0.md** — the current campaign-level curriculum/content audit.
- **data/SSS_STATIC_CONTENT_INVENTORY_v1.0.json** — the current machine-readable inventory supporting the master audit.
- **SSS_C1_CASE07_PREPRODUCTION_GAME_CONTENT_AUDIT_v1.0.md** — the Phase 1 game-content audit, evidence/reachability record, science alignment, and worksheet planning crosswalk for Campaign 1 Case 07. It is documentation only and does not create a curriculum package.

## Versioning

- v1.0 files are current.
- Older audit and inventory versions remain retained for traceability.

## Canonical source

The canonical released-case game source is recorded by each approved case. A pre-production case audit records both its pre-correction baseline and proposed frozen post-audit game commit; it does not advance curriculum lifecycle or release state.
