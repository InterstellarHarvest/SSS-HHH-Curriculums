# SSS Curriculum Audit

This directory holds the curriculum and content audit for **Space Sprout Sleuth (SSS)**.

## Current files

- **SSS_MASTER_AUDIT_v1.0.md** — the current campaign-level curriculum/content audit.
- **data/SSS_STATIC_CONTENT_INVENTORY_v1.0.json** — the current machine-readable inventory supporting the master audit.
- **SSS_C1_CASE07_PREPRODUCTION_GAME_CONTENT_AUDIT_v1.0.md** — the Phase 1 game-content audit, evidence/reachability record, science alignment, and worksheet planning crosswalk for Campaign 1 Case 07. It is documentation only and does not create a curriculum package.
- **SSS_C2_CAMPAIGN_COMPLETION_AUDIT_v1.0.md** — the Campaign 2 completion audit: per-case reconciliation of Cases 01–06, cross-campaign consistency, game-to-curriculum crosswalk, release integrity, shared editor/validation findings, and the cleanup-audit root cause. It is documentation only. It records one blocker and thirty-four major defects inside approved packages, and it does not modify any approved case package, release history, approval record, or frozen DOM baseline.
- **SSS_C2_MAINTENANCE_CLOSURE_v1.0.md** — the Campaign 2 maintenance and closure record. It is not an audit. It records the mechanical finalization of the Campaign 2 baseline: preflight verification, source certification and frozen-baseline results for the six current releases, the shared-validator repairs, the cleanup-audit retirement, documentation synchronization, the final-tip validation totals, and the remaining issues split into unresolved defects, deliberately preserved historical inaccuracies, and quality questions deferred to the later whole-SSS audit. It performs no curriculum-quality review and makes no claim that one has passed.

## Versioning

- v1.0 files are current.
- Older audit and inventory versions remain retained for traceability.

## Canonical source

The canonical released-case game source is recorded by each approved case. A pre-production case audit records both its pre-correction baseline and proposed frozen post-audit game commit; it does not advance curriculum lifecycle or release state.
