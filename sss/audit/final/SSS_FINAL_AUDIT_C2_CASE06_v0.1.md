## Overall assessment

The First Garden is a strong campaign finale in evidence boundaries, scientific caution, regulation/engineering constraints, and Answer Key completeness. It consistently frames mycorrhizal re-establishment as a **candidate cause**, never as a proven diagnosis or guaranteed cure. The chemical survey is correctly limited to chemistry, `trace levels only` never becomes zero, and the final engineering task requires identification, screening, approval, untreated controls, and monitoring rather than an inoculation recipe.

The dominant defects are Teacher-production defects: the eight-page Guide does not follow the common template, contains no timed instructional procedure, contains no common grading rubric, and contains no printed authoritative reference list. The recurring Accessible five-source synthesis burden also remains.

## C2C6-T01 — Teacher template drift

The Teacher Guide uses eight pages. Existing content is distributed as task-specific notes, science boundaries, evidence/precision ledger, standards discussion, and safety/regulatory guidance rather than the corrected C1 Case 01 page roles.

### Required remediation

Normalize the strong existing content into the common seven-page Teacher architecture while preserving:

- tested-versus-never-tested scope reasoning
- site-survey limitations
- candidate-cause language
- mycorrhizal-science boundaries
- biosafety/approval constraints
- precision ledger
- prohibition on guaranteed inoculation claims

## C2C6-T02 — no timed Teacher procedure

Teacher Pages 3–6 contain substantive notes for Tasks 1–7, but the Guide does not provide a timed procedure, period plan, or coherent launch → investigate → analyze → diagnose/model → explain → engineer sequence.

This differs from C2 Case 05, which explicitly states a two-period implementation. Here, no operational classroom route is stated.

### Required remediation

Create a complete detailed Teacher procedure that explicitly covers all seven tasks and provides a realistic core instructional route. If the case genuinely requires multiple periods, declare that clearly and divide the tasks intentionally rather than leaving pacing implicit.

## C2C6-T03 — no common grading rubric

The Teacher Guide contains task notes and answer guidance but no performance-level scoring rubric.

### Required remediation

Restore the common scoring system:

1. quick `Secure / Developing / Beginning` rubric
2. complete `4 / 3 / 2 / 1` analytic rubric

Useful case-specific dimensions include:

- scope of testing / clean-panel reasoning
- survey interpretation and limits
- candidate-cause evidence
- source contribution and limitations
- mechanism ordering and uncertainty
- bounded CER
- ecological/biosafety trial design

## C2C6-T04 — authoritative references absent

Teacher Page 7 carefully explains established Earth mycorrhizal science and overclaims to reject. Page 8 supplies precision/standards guidance. However, the printable Teacher Guide does not provide the authoritative references that support those Earth-science claims.

### Required remediation

Restore the Case 01 final-page source function by listing the controlled authoritative sources already used during production. A source-status paragraph is not a substitute for a reference list.

**PASS / preserve**

- `approximately four to six metres` remains a range, not an average
