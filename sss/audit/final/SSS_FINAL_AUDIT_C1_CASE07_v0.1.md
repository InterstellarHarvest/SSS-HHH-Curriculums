## C1C7-T01 — Teacher Edition template drift

Case 07 uses eight Teacher pages with strong content distributed across overview/standards, pacing, task-specific guidance, evidence ledger, diagnosis/misconceptions, intervention controls, accessibility/rubrics, and source ledger.

This is coherent internally but does not function as the same seven-page Teacher template used by corrected Case 01.

### Required remediation

Normalize the strong existing content into the seven-page common architecture. Preserve:

- evidence-status ledger
- strong science/fiction boundaries
- intervention monitoring/stopping rules
- full quick + analytic rubric
- source ledger

Case 07 demonstrates that the common template can support advanced case-specific content without becoming a separate document design.

## C1C7-T02 — pacing order conflicts with Student order

Teacher Page 2 pacing says:

- 28–38: compare diagnoses **and interventions**
- 38–51: complete dedicated CER

But the task order is:

- Task 5 diagnosis
- Task 6 CER
- Task 7 intervention

Later Teacher pages present Task 6 before Task 7 correctly.

### Required remediation

Normalize pacing to the Student/registry order unless a documented pedagogical reason explicitly requires otherwise. The simplest correction is diagnosis → CER → intervention → synthesis/exit.

## C1C7-UI01 — Task 5 best diagnosis not digitally persisted

Student and Accessible Task 5 tell learners to circle the best-supported diagnosis after completing comparison rows.

No separate persisted selection control is provided.

### Required remediation

Add a keyboard-operable single-selection control or explicit persisted `Best-supported diagnosis` field.

This continues the systemic selection defect found in C1 Cases 03–06.

## C1C7-UI02 — Task 4 missing-stage X marks cannot be recorded cleanly

Task 4 requires three separate operations:

1. place all six phrases
2. put an X beside every stage the isolated lab cannot currently supply
3. explain how the first missing stage interrupts the chain

The phrase boxes and explanation are persisted responses. There is no separate persisted representation for the required X marks.

### Required remediation

Add a clear digital stage-status control (for example `AVAILABLE / MISSING` or a persisted X marker) that is keyboard operable and prints cleanly.

This should also be represented in the Accessible edition.

## C1C7-AK01 — Answer Key does not complete Task 4 X-mark subpart

The Answer Key correctly completes all six mechanism phrases and explains that the isolated lab lacks the mature source and an available path.

However, it never visibly marks the Student-required unavailable stages with X/status markers.

### Required remediation

Show the completed unavailable-stage status directly on the Answer Key figure. A completed exemplar must visibly answer the same subpart the learner is asked to complete.
